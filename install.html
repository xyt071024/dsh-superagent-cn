安装与无损升级（v0.4.0）

三种装法，按你的环境选择。

方式一：一键在线安装脚本

适合已安装 Node.js 22.19+（或 24+）与 DSH（0.2.2+）的环境。脚本会自动解析 GitHub 最新正式版、校验 gzip 与 SHA-256，并在独立 superagent profile 中完成安装。

Windows（PowerShell）：

irm https://xyt071024.github.io/dsh-superagent-cn/install.ps1 | iex

macOS / Linux（Bash）：

curl -fsSL https://xyt071024.github.io/dsh-superagent-cn/install.sh | bash

方式二：四平台零依赖内置包

不需要预装 Node 或 DSH。下载对应你系统的包，解压，运行启动脚本。

系统下载（v0.4.0）
Windows x64Super-Agent-Bundled-Windows-x64-v0.4.0.zip · 约 195 MB
macOS Apple Silicon
（M1/M2/M3/M4）		Super-Agent-Bundled-macOS-arm64-v0.4.0.zip · 约 194 MB
macOS IntelSuper-Agent-Bundled-macOS-x64-v0.4.0.zip · 约 193 MB
Linux x64Super-Agent-Bundled-Linux-x64-v0.4.0.zip · 约 202 MB

步骤

  1. 解压到任意可写目录
    不要放 C:\Program Files 或需要管理员权限的位置。
  2. 运行启动脚本
    系统运行
    Windows双击 start.cmd
    macOS / Linux./start.sh
  3. 它会自动做三件事
    • 把 profile 装到 ~/.dsh/profiles/superagent
    • 选一个空闲端口（3082–3182）
    • 启动面板
  4. 打开面板
    终端会打印地址，形如 http://127.0.0.1:3087。

无损升级与强杀恢复：如果已有旧版 profile，启动脚本会自动备份并无损升级 dsh-superagent 插件，保留原有的 cordis.patch.yml 与其他插件。v0.4.0 新增 PID 感知状态目录锁：活实例绝不会被并发启动误抢锁，Windows 异常强杀后无需等待 30 秒即可 0 秒安全重启。

方式三：独立插件包

已经装了 DSH 且需要离线安装时使用。

dsh plugin add ./Super-Agent-Plugin-v0.4.0.tgz

或指定 profile：

dsh plugin --profile superagent add ./Super-Agent-Plugin-v0.4.0.tgz

下载：Super-Agent-Plugin-v0.4.0.tgz · 约 0.4 MB

需要 Node.js 22.19+（或 24+）与已安装的 DSH（0.2.2+）。

装完之后

1. 配置模型与分工参数

先在 DSH 中配置可用模型，再打开「超级代理人 → 设置」检查：

  • 会话分工与模型 —— 默认每任务最多 5 个独立分工对话（无固定上限），可按槽位指定不同模型或留空严格继承主对话模型
  • 上下文与预算 —— 默认 60% 上下文接力阈值与每日 Token 预算

2. 推荐先跑一个只读任务

在目标工作区新建聊天并选择 Super Agent 自动分工预设，输入例如：「请分别核对项目的安装说明、配置示例和更新日志，各自给出文件依据，最后汇总」，体验多对话独立协作后再按需启用外部来源。

3. 按需配置外部来源与独立复查

  • GitHub / 飞书 / 个人 QQ、微信、企业微信（OneBot）/ 官方 QQBot / IMAP+SMTP 邮箱（含 Gmail） —— 在「设置 → 来源」中按向导配置并点击检查，缺项会精确报错。
  • 独立复查 —— 在「设置 → 执行 / 路由」开启后，复杂工单完成后会另开只读独立审查员（作者不可自审），最多复审 3 轮；代码工作项始终强制校验受控测试凭据。

验证边界与已知限制

自动分工与独立复查默认关闭。 拆分多人协作会增加 token 消耗，请在设置页按需启用。

外部渠道与商业模型实测： 已验证协议行为、错误映射与自动化回归；七条外部渠道的真实账号收发与真实商业模型吞吐请按你的环境实测。

macOS / Linux 物理真机： 已通过 Linux CI 全量 1,393 项测试、包结构、Unix 权限位与原生模块校验，但尚未在物理 macOS / Linux 桌面双击实跑。

卸载

dsh plugin remove dsh-superagent

内置包装的还可删掉独立 profile：

rm -rf ~/.dsh/profiles/superagent

Windows：rmdir /s %USERPROFILE%\.dsh\profiles\superagent

遇到问题

  • 启动脚本一闪就关 —— 在终端里运行查看完整报错
  • 提示状态目录被占用（ELOCKED） —— 报错会列出当前持有锁的活跃 PID，请先正常关闭旧实例
  • 端口被占 —— 它会自动切换，确认 127.0.0.1 后的端口与终端打印一致

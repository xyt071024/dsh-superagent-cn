Install

Two ways. Pick the one that fits your setup.

Option 1: Bundled

No need to pre-install Node or DSH. Download the package for your system, unzip, run the start script.

Steps

  1. Unzip anywhere
    Avoid C:\Program Files or locations needing admin rights.
  2. Run the start script
    SystemCommand
    Windowsdouble-click start.cmd
    macOS / Linux./start.sh
  3. It does three things automatically
    • Installs the profile to ~/.dsh/profiles/superagent
    • Picks a free port (3082–3182)
    • Starts the panel
  4. Open the panel
    The terminal prints the address, e.g. http://127.0.0.1:3087.

If the profile already exists, the launcher backs up and upgrades dsh-superagent in place while preserving your existing cordis.patch.yml and other plugins.

Option 2: Plugin package

If DSH is already installed, use this.

dsh plugin add ./Super-Agent-Plugin-v0.3.17.tgz

Or a specific profile:

dsh plugin --profile superagent add ./Super-Agent-Plugin-v0.3.17.tgz

Download: Super-Agent-Plugin-v0.3.17.tgz · 0.4 MB

Requires Node.js 22.19+ and DSH 0.2.2.

After installing

1. Configure sources

Open Settings → Sources and configure the channels you need:

  • QQ — OneBot gateway URL and token; "Check" actually connects
  • Email — address and password; IMAP and SMTP are checked separately
  • GitHub — token and repository
  • Feishu — App ID / Secret

A misconfiguration names what is missing instead of just showing "waiting for deployment check".

2. Optional: multi-agent collaboration

Single-agent execution is the default. To split one ticket across several members:

Settings → Execution → Multi-session → auto

Splitting significantly increases token usage.

3. Optional: independent review

Settings → Execution → Independent review → on

A read-only reviewer is spawned after complex tickets. It never sees the execution trace. Up to 3 review rounds.

Known limitations

Multi-session and independent review are off by default.

No real send/receive verification for any channel. Protocol behaviour and error mapping are verified; real-account login, send, receive and reconnect are not.

macOS / Linux not verified on real hardware. Package structure and native modules are correct, but neither has been launched on those systems.

Uninstall

dsh plugin remove dsh-superagent

For the bundled package, also remove the profile:

rm -rf ~/.dsh/profiles/superagent

Windows: rmdir /s %USERPROFILE%\.dsh\profiles\superagent

Troubleshooting

  • Start script closes instantly — run it from a terminal to see the error
  • Port in use — it picks another one automatically; check the address printed
  • Panel won't open — make sure the port after 127.0.0.1 matches what the terminal printed

Install & Lossless Upgrade (v0.4.0)

Three ways to install. Pick the one that fits your setup.

Option 1: One-Line Installer

For machines that already have Node.js 22.19+ (or 24+) and DSH 0.2.2+. Dynamically resolves the latest stable release, verifies gzip magic bytes and SHA-256, and configures an isolated superagent profile without overwriting existing settings.

Windows (PowerShell):

irm https://xyt071024.github.io/dsh-superagent-cn/install.ps1 | iex

macOS / Linux (Bash):

curl -fsSL https://xyt071024.github.io/dsh-superagent-cn/install.sh | bash

Option 2: Zero-Dependency Bundled Archives

No need to pre-install Node or DSH. Download the package for your system, unzip, and run the start script.

Steps

  1. Unzip into any writable directory
    Avoid C:\Program Files or locations needing admin rights.
  2. Run the start script
    SystemCommand
    Windowsdouble-click start.cmd
    macOS / Linux./start.sh
  3. It does three things automatically
    • Installs the profile to ~/.dsh/profiles/superagent
    • Picks a free port (3082–3182)
    • Starts the panel
  4. Open the panel
    The terminal prints the address, e.g. http://127.0.0.1:3087.

Lossless upgrade & crash recovery: If the profile already exists, the launcher backs up and upgrades dsh-superagent in place while preserving your cordis.patch.yml and other plugins. v0.4.0 adds PID-aware state directory locking so live instances are never clobbered while hard-killed Windows instances recover immediately at 0s.

Option 3: Standalone Plugin Package

If DSH is already installed and you prefer offline installation:

dsh plugin add ./Super-Agent-Plugin-v0.4.0.tgz

Or a specific profile:

dsh plugin --profile superagent add ./Super-Agent-Plugin-v0.4.0.tgz

Download: Super-Agent-Plugin-v0.4.0.tgz · ~0.4 MB

Requires Node.js 22.19+ (or 24+) and DSH 0.2.2+.

After Installing

1. Configure models & division slots

Connect a model in DSH, then review Settings → Division & Models (default allowance 5, freely adjustable, per-slot overrides or strict origin-window inheritance) and Context & Budget (60% relay threshold).

2. Try a read-only task first

Open a chat in your workspace with the Super Agent preset and try a read-only multi-file review before connecting external accounts.

3. Optional sources & independent review

  • Sources: GitHub, Feishu, Personal QQ / WeChat / WeCom (OneBot), Official QQBot, and IMAP/SMTP Email (including Gmail).
  • Independent review: Spawns a read-only reviewer (never the author) for up to 3 rework rounds; code work items always enforce real managed test verification.

Verification Scope & Known Limitations

Multi-session division and independent review are off by default (enable in Settings; splitting increases token usage).

Live channels & commercial models: Protocol behavior and regressions are verified; live external account send/receive and commercial LLM API throughput should be validated in your own environment.

macOS / Linux physical hardware: Linux CI runs 1,393 automated tests and ZIP structure/permissions/native modules are verified, but physical desktop launches on macOS/Linux have not been executed here.

Uninstall

dsh plugin remove dsh-superagent

For the bundled package, also remove the profile:

rm -rf ~/.dsh/profiles/superagent

Windows: rmdir /s %USERPROFILE%\.dsh\profiles\superagent

Troubleshooting

  • Start script closes instantly — run it from a terminal to see the full error
  • State lock held (ELOCKED) — the message prints the live owning PID; stop that instance cleanly instead of removing lock files manually
  • Port in use — it picks a free port automatically; open the exact 127.0.0.1:<port> printed in the terminal

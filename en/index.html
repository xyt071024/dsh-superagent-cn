An agent that looks for work

Receives work from any source · decides whether to take it · splits hard problems across models · reports back when done.

Start reading GitHub repository
⇄

Multi-source intake

GitHub, Feishu, WeCom, email, QQ, WeChat — one unified entry point.

⛊

Three-layer authorization

Gate (code) → Assessment (model) → Mandate (credential). Message content cannot change permissions.

⋔

Multi-session collaboration

Hard tasks split into sub-sessions with different models, running in parallel and rescuing each other when stuck.

↻

Self-evolution

Reflect → record lessons → optimize itself. Better at the same task each time.

Assign complex work from a main chat, let independent division sessions run parallel parts with per-slot model routing, enforce real test verification and independent review, and rely on 60% lossless context relay, Outbox-authoritative delivery, and PID-aware crash recovery.

7-Channel Intake & Code Gate

Unifies DSH workspace chat, GitHub, Feishu, Personal QQ, Official QQBot, WeChat, WeCom, and IMAP/SMTP Mail (Gmail) behind allowlist gates, semantic checks, and scoped credentials.

⋔

Elastic Divisions & Models

Defaults to 5 independent division sessions per task (freely adjustable with no fixed cap, paginated UI, sparse storage), per-slot model overrides or strict task-start model inheritance, plus peer coordination.

✓

Mandatory Code Checks & Review

Code work items reject manual acceptance and require managed test evidence bound to the delivered revision; read-only independent reviewers forbid self-review and guide up to 3 rework rounds.

↻

60% Relay & Instant Crash Recovery

All session roles hand over cleanly at 60% context (r1→r2→r3); speculative drafts track authoritative Outbox receipts; v0.4.0 PID-aware state locking protects live instances and recovers at 0s after hard-kill.

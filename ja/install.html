インストールと無損失アップグレード（v0.4.0）

3 通りの導入方法があります。環境に合わせて選んでください。

方法 1：ワンライナー導入スクリプト

Node.js 22.19+（または 24+）と DSH 0.2.2+ が導入済みの環境向けです。GitHub 最新安定版を動的に取得し、gzip と SHA-256 を検証して独立 superagent プロファイルに構成します。

Windows（PowerShell）：

irm https://xyt071024.github.io/dsh-superagent-cn/install.ps1 | iex

macOS / Linux（Bash）：

curl -fsSL https://xyt071024.github.io/dsh-superagent-cn/install.sh | bash

方法 2：4 プラットフォーム同梱バンドル版

Node も DSH も事前インストール不要です。お使いのシステム用パッケージをダウンロードし、解凍して起動スクリプトを実行します。

手順

  1. 書き込み可能な任意の場所へ解凍
    C:\Program Files など管理者権限が必要な場所は避けてください。
  2. 起動スクリプトを実行
    システムコマンド
    Windowsstart.cmd をダブルクリック
    macOS / Linux./start.sh
  3. 自動で 3 つの処理を行います
    • プロファイルを ~/.dsh/profiles/superagent に配置
    • 空きポートを選択（3082–3182）
    • パネルを起動
  4. パネルを開く
    ターミナルに http://127.0.0.1:3087 のようなアドレスが表示されます。

無損失アップグレード＆強制終了復旧：プロファイルが既に存在する場合、起動スクリプトが自動でバックアップを取り、既存の cordis.patch.yml と他プラグインを保持したまま dsh-superagent をアップグレードします。v0.4.0 の PID 認識ロックは稼働中インスタンスを保護しつつ、Windows 強制終了後 0 秒で安全に再起動できます。

方法 3：単体プラグインパッケージ

DSH が既にインストール済みでオフライン導入したい場合：

dsh plugin add ./Super-Agent-Plugin-v0.4.0.tgz

プロファイルを指定する場合：

dsh plugin --profile superagent add ./Super-Agent-Plugin-v0.4.0.tgz

ダウンロード：Super-Agent-Plugin-v0.4.0.tgz · 約 0.4 MB

Node.js 22.19+（または 24+）と DSH 0.2.2+ が必要です。

インストール後

1. モデルと分担設定を確認

DSH でモデルを接続後、「設定 → 分担とモデル」（既定 5、上限撤廃・スロット別モデル指定／開始ウィンドウ継承）と「コンテキストと予算」（既定 60% リレー）を確認します。

2. まず読み取り専用タスクで試用

ワークスペースで Super Agent プリセットを選び、まずドキュメント確認などの読み取り専用タスクで複数セッション並列動作を確認してから外部アカウントを接続してください。

3. 任意：外部ソースと独立レビュー

  • 対応ソース：GitHub、Feishu、個人 QQ / WeChat / WeCom（OneBot）、公式 QQBot、IMAP/SMTP メール（Gmail 対応）。
  • 独立レビュー：複雑なチケット後に作成者以外の読み取り専用レビュー担当を起動（最大 3 ラウンド）。コード項目は常にテスト証跡を強制検証します。

検証範囲と既知の制限

マルチセッションと独立レビューは既定でオフです。 分割によりトークン消費が増えるため、設定画面から必要に応じて有効化してください。

外部チャネルと商用モデル実測： プロトコル動作と回帰テストは検証済みですが、実アカウントでの送受信や商用モデル実スループットは利用環境でご確認ください。

macOS / Linux 実機デスクトップ： Linux CI で 1,393 件の自動テストおよび ZIP 権限・ネイティブ構成を検証済みですが、物理実機でのダブルクリック起動は未実施です。

アンインストール

dsh plugin remove dsh-superagent

バンドル版の場合はプロファイルも削除します：

rm -rf ~/.dsh/profiles/superagent

Windows：rmdir /s %USERPROFILE%\.dsh\profiles\superagent

トラブルシューティング

  • 起動スクリプトがすぐ閉じる — ターミナルから実行してエラー詳細を確認してください
  • 状態ロック競合（ELOCKED） — 稼働中 PID が表示されます。ロックを手動削除せず既存インスタンスを終了してください
  • ポートが使用中 — 自動的に空きポートを選びます。ターミナル表示の 127.0.0.1:<port> を開いてください

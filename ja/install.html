インストール

2 通りの方法があります。環境に合わせて選んでください。

方法 1：バンドル版

Node も DSH も事前インストール不要です。お使いのシステム用パッケージをダウンロードし、解凍して起動スクリプトを実行します。

システムダウンロード
Windows x64Super-Agent-Bundled-Windows-x64-v0.3.16.zip · 195 MB
macOS Apple Silicon
(M1/M2/M3/M4)		Super-Agent-Bundled-macOS-arm64-v0.3.16.zip · 194 MB
macOS IntelSuper-Agent-Bundled-macOS-x64-v0.3.16.zip · 193 MB
Linux x64Super-Agent-Bundled-Linux-x64-v0.3.16.zip · 202 MB

手順

  1. 任意の場所に解凍
    C:\Program Files など管理者権限が必要な場所は避けてください。
  2. 起動スクリプトを実行
    システムコマンド
    Windowsstart.cmd をダブルクリック
    macOS / Linux./start.sh
  3. 自動で 3 つの処理を行います
    • プロファイルを ~/.dsh/profiles/superagent に配置
    • 空きポートを選択（3082–3182）
    • パネルを起動
  4. パネルを開く
    ターミナルに http://127.0.0.1:3087 のようなアドレスが表示されます。

プロファイルが既に存在する場合、起動スクリプトが自動でバックアップを取り、既存の cordis.patch.yml と他プラグインを保持したまま dsh-superagent をアップグレードします。

方法 2：プラグインパッケージ

DSH が既にインストール済みの場合。

dsh plugin add ./Super-Agent-Plugin-v0.3.16.tgz

プロファイルを指定する場合：

dsh plugin --profile superagent add ./Super-Agent-Plugin-v0.3.16.tgz

ダウンロード：Super-Agent-Plugin-v0.3.16.tgz · 0.4 MB

Node.js 22.19+ と DSH 0.2.2 が必要です。

インストール後

1. ソースの設定

設定 → ソース を開き、使用するチャネルを設定します：

  • QQ — OneBot ゲートウェイの URL とトークン。「確認」で実際に接続します
  • メール — アドレスとパスワード。IMAP と SMTP は個別に確認されます
  • GitHub — トークンとリポジトリ
  • Feishu — App ID / Secret

設定に誤りがある場合、「デプロイ確認待ち」ではなく不足している項目が表示されます。

2. 任意：マルチエージェント協調

既定は単一エージェント実行です。1 つのチケットを複数メンバーに分割する場合：

設定 → 実行 → マルチセッション → auto

分割するとトークン消費が大幅に増えます。

3. 任意：独立レビュー

設定 → 実行 → 独立レビュー → オン

複雑なチケットの後に読み取り専用のレビュー担当が起動します。実行過程は見えません。最大 3 回まで再レビューします。

既知の制限

マルチセッションと独立レビューは既定でオフです。

各チャネルの実送受信は未検証です。 プロトコル動作とエラーマッピングは検証済みですが、実アカウントでのログイン・送受信・再接続は未検証です。

macOS / Linux は実機で起動検証していません。 パッケージ構造とネイティブモジュールは正しいですが、実際には起動していません。

アンインストール

dsh plugin remove dsh-superagent

バンドル版の場合はプロファイルも削除します：

rm -rf ~/.dsh/profiles/superagent

Windows：rmdir /s %USERPROFILE%\.dsh\profiles\superagent

トラブルシューティング

  • 起動スクリプトがすぐ閉じる — ターミナルから実行してエラーを確認してください
  • ポートが使用中 — 自動的に別のポートを選びます。表示されたアドレスを確認してください
  • パネルが開かない — 127.0.0.1 の後ろのポートがターミナルの表示と一致しているか確認してください
